   8052 片内外设特殊功能寄存器详解

//中断相关寄存器

1.IE 中断允许寄存器

IE (A8H)  位地址: AFH   AEH   ADH   ACH   ABH   AAH   A9H   A8H
         ┌────┬────┬────┬────┬────┬────┬────┬────┐
         │ EA │  - │ ET2│ ES │ ET1│ EX1│ ET0│ EX0│
         └────┴────┴────┴────┴────┴────┴────┴────┘
           7    6    5    4    3    2    1    0

说明：
EA  = 全局中断允许
ET2 = 定时器2中断允许（52子系列）
ES  = 串口中断允许
ET1 = 定时器1中断允许
EX1 = 外部中断1允许
ET0 = 定时器0中断允许
EX0 = 外部中断0允许

2. IP 中断优先级寄存器

IP (B8H)  位地址: BFH   BEH   BDH   BCH   BBH   BAH   B9H   B8H
         ┌────┬────┬────┬────┬────┬────┬────┬────┐
         │  - │  - │ PT2│ PS │ PT1│ PX1│ PT0│ PX0│
         └────┴────┴────┴────┴────┴────┴────┴────┘
           7    6    5    4    3    2    1     0

说明：
PT2 = 定时器2优先级
PS  = 串口优先级
PT1 = 定时器1优先级
PX1 = 外部中断1优先级
PT0 = 定时器0优先级
PX0 = 外部中断0优先级


3.中断源总览

中断号   入口地址   中断源           使能位   标志位
  0      0003H     外部中断0         EX0      IE0
  1      000BH     定时器0溢出       ET0      TF0
  2      0013H     外部中断1         EX1      IE1
  3      001BH     定时器1溢出       ET1      TF1
  4      0023H     串口收发          ES       TI/RI
  5      002BH     定时器2溢出(52)   ET2      TF2

// 定时器相关特殊功能寄存器

4. TMOD 定时器配置寄存器
+---------------------------------------------------------------+
|                          TMOD (89H)                           |
+-------+-------+-------+-------+-------+-------+-------+-------+
| Bit 7 | Bit 6 | Bit 5 | Bit 4 | Bit 3 | Bit 2 | Bit 1 | Bit 0 |
+-------+-------+-------+-------+-------+-------+-------+-------+
| GATE  | C/T#  |  M1   |  M0   | GATE  | C/T#  |  M1   |  M0   |
+-------+-------+-------+-------+-------+-------+-------+-------+
|          Timer 1 控制区       |          Timer 0 控制区       |
+---------------------------------------------------------------+

功能说明：
GATE  ：门控位，1 时由 INTx 与 TRx 共同启动
C/T#	：0 = 定时，1 = 计数
M1/M0	：工作模式选择 (00~11)

5. TCON 定时器控制寄存器

+---------------------------------------------------------------+
|                          TCON (88H)                           |
+-------+-------+-------+-------+-------+-------+-------+-------+
| Bit 7 | Bit 6 | Bit 5 | Bit 4 | Bit 3 | Bit 2 | Bit 1 | Bit 0 |
+-------+-------+-------+-------+-------+-------+-------+-------+
|  TF1  |  TR1  |  TF0  |  TR0  |  IE1  |  IT1  |  IE0  |  IT0  |
+-------+-------+-------+-------+-------+-------+-------+-------+
|     Timer 1   |    Timer 0    |    外部中断 1 |  外部中断 0   |
+---------------------------------------------------------------+

功能说明：
TF1  : Timer1 溢出标志
TR1  : Timer1 运行控制
TF0  : Timer0 溢出标志
TR0  : Timer0 运行控制
IE1  : 外部中断1标志
IT1  : 外部中断1触发方式
IE0  : 外部中断0标志
IT0  : 外部中断0触发方式

//串口相关特殊寄功能存器

6. SCON 串口控制寄存器（98H）

        SCON  (98H)
位序:     7      6      5      4      3      2      1      0
       ┌──────┬──────┬──────┬──────┬──────┬──────┬──────┬──────┐
       │  SM0 │  SM1 │  SM2 │  REN │  TB8 │  RB8 │  TI  │  RI  │
       └──────┴──────┴──────┴──────┴──────┴──────┴──────┴──────┘
位地址:  9FH    9EH    9DH    9CH    9BH    9AH    99H    98H

功能说明：
SM0、SM1：	串口工作方式选择
	 SM2：  多机通信控制位
	 REN：	串口接收允许
     TB8：  方式 2/3 发送的第 9 位
     RB8：	方式 2/3 接收的第 9 位
      TI：	发送中断标志
      RI：	接收中断标志

7. PCON 电源控制寄存器（87H）

        PCON  (87H)
        ┌──────┬──────┬──────┬──────┬──────┬──────┬──────┬──────┐
        │ SMOD │  -   │  -   │  -   │ GF1  │ GF0  │ PD   │ IDL  │
        └──────┴──────┴──────┴──────┴──────┴──────┴──────┴──────┘
位序:     7      6      5      4      3      2      1      0

说明：
SMOD：串口波特率加倍位（1 = 加倍）
